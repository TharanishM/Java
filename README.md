# ✊🖐✌ Rock Paper Scissors Game

A simple **Rock Paper Scissors** game developed in **Java** using Object-Oriented Programming (OOP) concepts. The game allows a player to compete against the computer with randomly generated moves.

## 🚀 Tech Stack

- ☕ Java
- 💻 Object-Oriented Programming (OOP)

## ✨ Features

- 🎮 Play against the computer
- 🎲 Random computer moves
- 🏆 Winner determination
- 🔄 Multiple rounds (if implemented)
- 📚 Clean OOP-based code structure

## 📄 Project Structure

```
Rock-Paper-Scissors/
├── Main.java
├── Game.java
└── RPS.java
```

## ▶️ How to Run

1. Compile the Java files:
   ```bash
   javac *.java
   ```

2. Run the application:
   ```bash
   java Main
   ```
